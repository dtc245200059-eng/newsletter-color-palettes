Hướng dẫn Nộp bài (GitHub & CodePen)

Bạn có thể chọn nộp bài qua GitHub Repository (kèm GitHub Pages) hoặc tạo bài đăng trên CodePen theo các bước chi tiết dưới đây:

Cách 1: Đưa lên GitHub (Khuyên dùng)

Giúp lưu trữ toàn bộ dự án gồm cả 2 phiên bản và trang showcase tổng hợp:

  1. Mở Terminal tại thư mục dự án và khởi tạo Git: 
    git init
git add .
git commit -m "feat: redesign newsletter color palettes with Adobe Color"
  2. Tạo một Repository mới trên GitHub (ví dụ: newsletter-color-palettes).
  3. Liên kết và đẩy mã nguồn lên GitHub: 
    git remote add origin https://github.com/USERNAME/newsletter-color-palettes.git
git branch -M main
git push -u origin main
  4. (Tùy chọn) Bật GitHub Pages trong Settings > Pages > Branch: main để có trang web chạy trực tuyến.
Cách 2: Đưa lên CodePen

Dành cho việc trình bày nhanh từng phiên bản trực tuyến:

  1. Truy cập codepen.io/pen và đăng nhập tài khoản.
  2. Mở file newsletter_version1.html (hoặc newsletter_version2.html).
  3. Vào mục Settings > CSS của CodePen:
    https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css
    https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css
  4. Copy phần trong thẻ <style> vào khung CSS, phần trong thẻ <body> vào khung HTML.
  5. Nhấn Save và lấy liên kết URL của Pen để dán vào phần nộp bài.
